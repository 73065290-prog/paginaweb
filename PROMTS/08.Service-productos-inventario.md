## 1. Contexto

Actualmente, las reglas de productos e inventario se encuentran distribuidas principalmente en:

- `includes/data.php`
- `includes/functions.php`

Además, existen validaciones implementadas mediante funciones independientes.

La clase `ProductoValidator` existe, pero actualmente no tiene consumidores reales.

Esta distribución dificulta mantener la lógica del sistema, reutilizar las validaciones y separar correctamente las responsabilidades entre las vistas, los servicios y el acceso a datos.

El PROMPT 06 contiene el mapa de dependencias que debe utilizarse como referencia para identificar las funciones y relaciones existentes.

El PROMPT 07 incorpora los modelos tipados del sistema, que deben aprovecharse cuando corresponda.

## 2. Objetivo

Crear una capa de servicios para centralizar las reglas de negocio relacionadas con productos e inventario.

Implementar:

- `backend/services/ProductoService.php`
- `backend/services/InventarioService.php`
- `backend/validators/ProductoValidator.php`

Los servicios deben concentrar las operaciones y reglas existentes de:

**Productos:**
- Alta de productos.
- Edición de productos.
- Validaciones de productos.
- Cálculo y gestión del margen.
- Validación de los datos correspondientes al EAN.

**Inventario:**
- Gestión del inventario.
- Reorden de inventario.
- Clasificación ABC.
- Control de stock por tienda.

Las funciones anteriores deben mantenerse como delegadoras para conservar la compatibilidad con el código existente.
