## 4. Objetivo

Crear `PedidoService` para centralizar la lógica de negocio relacionada con los pedidos y el proceso de checkout.

El servicio debe encargarse de:

- Validar los datos del pedido.
- Comprobar las condiciones de retiro y delivery express.
- Validar la dirección de entrega y los horarios.
- Calcular los totales del pedido.
- Aplicar el costo correspondiente al método de entrega.
- Crear y confirmar el pedido.
- Guardar el pedido en MySQL cuando exista conexión.
- Mantener el comportamiento de demostración basado en sesión cuando no exista conexión.
- Generar o conservar el código de pedido con el prefijo `MASS-`.
- Devolver la información de confirmación y tracking.

La lógica debe quedar centralizada en `PedidoService`. Las funciones antiguas deben conservarse como delegadoras cuando sea necesario para mantener la compatibilidad con el sistema existente.
