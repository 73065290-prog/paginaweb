## 3. Contexto del proyecto

`Database::connected()` puede hacer que `includes/data.php` se utilice en silencio cuando falla la conexión a MySQL. Ese comportamiento oculta el fallo y hace que el sistema parezca operativo aunque no esté usando la base de datos real.

En la matriz de seguimiento, la brecha G08 («Fallback silencioso a datos demo si MySQL no responde») está asociada a `INT-004-BOLT-002`. `INT-004-BOLT-004` corresponde a los repositorios PDO; su verificación contra MySQL real quedó en el prompt 17 y no autoriza editar esos repositorios en este prompt.

Se necesita un modo demo explícito, un aviso visible cuando esté activo o cuando falle MySQL, y retirar los datos duplicados de `includes/data.php` solo después de comprobar que los prompts 16 y 17 quedaron verificados y que el seed cubre lo que se va a borrar.

## 4. Objetivo

Implementar un modo explícito mediante `MASS_USE_DB`, mostrar un aviso visible en el panel de administración cuando se utilicen datos demo o falle la conexión a MySQL, y retirar los datos duplicados de `includes/data.php` únicamente cuando los prompts 16 y 17 estén verificados y el seed reemplace esos datos.
