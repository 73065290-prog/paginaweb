# PROMPT: Corrección de logout y cambio de rol (admin ↔ cliente)

## Problema
Al cerrar sesión o al cambiar de administrador a cliente (o viceversa), el flujo fallaba.

## Causa
`mass_asset('logout.php')` generaba la ruta incorrecta `frontend/assets/logout.php`.

## Correcciones esperadas
1. Separar `mass_url()` (páginas de la app) de `mass_asset()` (CSS/JS/IMG).
2. Actualizar el navbar para usar `mass_url('logout.php')` y rutas `admin/...`.
3. Permitir en el login el cambio de rol cerrando la sesión anterior.
4. Ejecutar PHPUnit y smoke de autenticación hasta que todo pase.
5. Subir los cambios a la rama `main` de GitHub e incluir este prompt en `PROMTS/`.
