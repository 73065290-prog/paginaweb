# Evidencias de ejecución

Archivos generados por `composer test:coverage` (no editar a mano):

- `ejecucion-automatizada.txt` — salida cruda de consola
- `junit.xml` — reporte JUnit
- `testdox.html` — listado legible de tests
- `coverage/clover.xml` — cobertura para SonarQube
- `coverage/html/` — informe HTML de cobertura
